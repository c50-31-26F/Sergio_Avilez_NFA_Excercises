# Problem 10 — Strings that do not contain substring `10`

## NFA

The language consists of strings with no occurrence of `10`. Therefore, once a `1` has been read, no later `0` is allowed.

![NFA screenshot](images/n10-nfa.png)

## Batch Run

Accepted strings are listed before rejected strings in `n10t.txt`.

![JFLAP Multiple Run screenshot](images/n10-batch-run.png)

## Gold-st-ring / challenging moment

A useful challenge string is `0010`. The machine reaches `q1` after the `1`, and the following `0` has no transition, so the input is rejected.

![Computation tree](images/n10-gold-tree.png)

![Step-by-State screenshot](images/n10-step-1.png)

![Step-by-State screenshot](images/n10-step-2.png)

## Notes

Valid strings have all of their `0`s before all of their `1`s. The two accepting states represent the cases where the machine has seen only zeros or has already moved into the ones portion.
