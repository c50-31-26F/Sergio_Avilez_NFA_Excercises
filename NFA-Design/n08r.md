# Problem 8 — Strings that start with `01` and end with `10`

## NFA

The first two symbols are forced to be `01`. After that, the NFA searches nondeterministically for the final `10`.

![NFA screenshot](images/n08-nfa.png)

## Batch Run

Accepted strings are listed before rejected strings in `n08t.txt`.

![JFLAP Multiple Run screenshot](images/n08-batch-run.png)

## Gold-st-ring / challenging moment

A useful challenge string is `01010`, because the NFA has more than one possible path while searching for the final `10`.

## Notes

This problem combines a required prefix with a required suffix. The middle portion can be any binary string.
